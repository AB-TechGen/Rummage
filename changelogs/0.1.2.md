# 0.1.2

Build of the latest Rummage features and automatic OpenDraft-style connection system under version **0.1.2**. All lobby members must use 0.1.2.

## Included in this build

| Area | Behavior |
| --- | --- |
| Automatic hosting | Create a lobby using the built-in Cloudflare Worker; normal players do not configure a relay. |
| Fallbacks | Try UPnP if the Worker is unavailable, then provide a direct/LAN invite with the actual port and connection explanation. |
| Direct connections | Race LAN/public addresses, accept host:port and IPv6 addresses, and select a free port when the preferred one is occupied. |
| Recovery and cleanup | Reclaim short codes with the host key, reconnect players, and remove automatic router mappings on lobby close or normal shutdown. |
| Existing gameplay | Biome-aware targets, seed filters, sudden death, lookout, race preset, fullbright, saved preferences, draw voting, recovery, world retention and signed-update support. |

## Changed

- Set the Gradle artifact version, Fabric metadata, lobby title, network version and cached-build output to **0.1.2**.
- Updated README installation and command examples for `rummage-0.1.2.jar`.
- Preserved previous version jars and changelogs.

## Validation

The automated suite covers 419 assertions, including real local TCP, TLS and WebSocket traffic, UPnP fallback and cleanup, reconnect identity, world retention and update verification. Mixin descriptor checks cover 15 targets/shadow fields. Live internet and in-game smoke testing remain separate from these checks.
