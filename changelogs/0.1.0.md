# 0.1.0

Initial playable release, originally named BlockShuffle and subsequently renamed Rummage.

## Added

| Area | Changes |
| --- | --- |
| Core game | Shared target blocks, timed rounds, elimination, solo practice and multiplayer for up to eight players. |
| Match flow | Loading barrier, five-second countdown, intermissions, forfeit, shared victory at the round cap and draws on simultaneous elimination. |
| Worlds | Fresh singleplayer worlds on a shared seed; inventory and world progress carry between rounds. |
| Targets | Curated progression: common blocks first, crafting/mining from round 4, Nether/rare blocks from round 9; no consecutive repeats. |
| Lobby | Title-screen entry, display names, invite copying, chat, standings and leader-controlled seed, duration and round cap. |
| Client | Automatic block detection, target/timer/status HUD, rebindable B key and spectator handling. |
| Networking | Direct TCP synchronizer, automatic reconnects with five-minute slot reservations, and a standalone synchronizer in the same jar. |
| Validation | Deterministic engine tests and local TCP integration checks. |

## Changed

- Renamed branding, Java packages, Fabric identifiers, resources, build artifacts and documentation from BlockShuffle to Rummage.

## Limitations at release

Direct invites required reachable LAN/VPN addresses or port forwarding. Recovery credentials and server state were in memory. Relay invites, seed filtering, standardized loot, lookout, draw voting, retention controls and signed updates were not included.
