# 1.0.0 — First official release

Promotes the tested 0.2.1 release candidate to the first official Rummage release. Gameplay and UI behavior are unchanged.

- Same-seed, separate-world block races for 1–8 players, including solo practice.
- Progression-gated, weighted targets with biome exclusions and repeat protection.
- Leader-only match settings, compact match/HUD panels, rebindable HUD/fullbright controls, and local lobby preferences.
- Coloured lobby/world chat, shared advancement announcements, and automatic return to the lobby after results.
- Always-on gameplay fairness, disabled Commands/LAN controls, and Easy/Normal/Hard difficulty with Peaceful replaced by Easy.
- Automatic relay hosting with direct/UPnP fallback and session recovery.

Minecraft 26.3, Java 25, Fabric Loader 0.19.5 or newer, and Fabric API are required. All lobby members must use 1.0.0. Replace the previous Rummage jar with rummage-1.0.0.jar while Minecraft is closed.

The maintainer reports extensive solo testing of the release candidate. Automated validation is rerun for the final 1.0.0 artifact; this promotion does not claim additional live multi-machine testing.

Release validation: Gradle build passed with 613 assertions and 19 mixin compatibility checks. Compiled classes were compared with the tested 0.2.1 jar and differ only in the release-version constants. A SHA-256 checksum accompanies the jar.
