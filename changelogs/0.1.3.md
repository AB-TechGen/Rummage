# 0.1.3

UI overhaul adapted to Rummage rounds and elimination rules.

- Separate lobby panels for players, settings and chat, with hidden invites and Enter shortcuts.
- Named settings tabs, numeric controls, filter pickers, tooltips and an HUD size slider.
- Dedicated in-game match panel with forfeit confirmation and draw actions.
- Compact target HUD, loading cover, countdown and result banners.
- Tab standings with dimension icons and optional in-world lobby chat.
- Consistent 0.1.3 build, Fabric metadata and lobby protocol version; all players must use 0.1.3.

Validation: Gradle build and engine/network suite; in-game visual smoke testing remains outstanding.
