# 0.1.1

Expanded match rules, connection options and player preferences. All lobby members must use the same version.

## Added

| Area | Changes |
| --- | --- |
| Target selection | Biome-aware exclusions and bamboo, moss, terracotta and snow targets from round 4. |
| Seed filters | Required biome/structure IDs, configurable search radius and up to eight generated-world attempts for random seeds. |
| Sudden death | Optional rounds past the cap with decreasing duration and a ten-second minimum. |
| Race preset | One-time starting supplies, reduced ordinary Nether fog and guaranteed pearl trades at barters 36, 72, 108 and 144. |
| Lookout | Optional aerial preview before the ground countdown. |
| Loot | Saved world-seeded sequences for block drops, mob loot tables and bartering, including shared stone/deepslate ore sequences. |
| Fullbright | Rebindable G toggle, subject to the leader's permission. |
| HUD | Target block icon, completion feedback, final-ten-second warning, visibility toggle and adjustable scale. |
| Standings | Rebindable P shortcut, dimension and measured ping alongside score and player status. |
| Preferences | Persistent names, match settings, local display choices and network/update configuration. |
| Recovery | Persistent reconnect credentials and match-world information for recovery after a client restart. |
| Draw voting | Thirty-second unanimous votes among connected survivors, withdrawal and cancellation on completion. |
| Latency handling | Server-measured compensation capped at 300 ms, plus a 300 ms deadline settlement window. |
| Worlds | Marked-world listing, protected favourites, optional retention and explicit cleanup with lock checks. |
| Fair play | Match-world restrictions on commands, LAN publishing, difficulty, game modes and rule edits. |
| Connections | Automatic OpenDraft-style Cloudflare Worker hosting, eight-character short codes, UPnP fallback, dual LAN/public invites, CGNAT warnings and host-code recovery. Normal players need no relay configuration. The earlier custom TLS transport remains compatible with old invites. |
| Updates | HTTPS manifests, Ed25519 signatures, SHA-256 checks, release-signing tool and exit-time installation with rollback backup. |

## Fixed

- Retry rejected random seeds without requiring a manual return to the lobby.
- Require world approval before the loading barrier advances.
- Preserve relay-code ownership across temporary host disconnects.
- Stop stale network writer threads when reconnecting.
- Stage updates before replacing the installed jar.
- Configure Gradle's `test` task to run `engineTest` and allow the expected absence of JUnit/TestNG tests, resolving the no-tests-discovered CI failure.
- Fall back from an occupied host port to a free port, and remove automatic UPnP mappings on lobby close or normal process shutdown.
- Connect to LAN/public invite addresses and alternative Workers concurrently; close losing connections.
- Replace normal relay/address setup fields with automatic connection status and a copyable invite.
- Refresh unchanged snapshots once per second while still broadcasting state changes promptly, reducing Worker traffic.
