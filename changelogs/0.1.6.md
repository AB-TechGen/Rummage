# 0.1.6

- Reworked the fullbright hook to adjust brightness during lightmap extraction instead of mutating cached state at render time.
- Removed forced per-frame lightmap rendering and synthetic night-vision values.
- Fullbright toggles and leaving a match request a complete vanilla lighting refresh, restoring ordinary lighting when disabled.
- Keeps the compact UI from 0.1.5. All players must use 0.1.6.

Addresses the reported black cave surfaces with fullbright enabled. In-game confirmation is still required; the intermittent native launch crash remains separately deferred.
