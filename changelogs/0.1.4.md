# 0.1.4

- Pre-game settings are leader-only and contain only Match and World choices.
- Biome-aware targets, standardized supported loot RNG, reduced Nether fog, guaranteed pearl trades and fair-play restrictions always apply in match worlds.
- Removed the race starting kit and all switches for the fixed gameplay rules.
- HUD and fullbright remain rebindable hotkeys; HUD size is adjusted in the in-game match panel.
- Player chat and world retention are personal lobby controls.
- Removed the unconfigured update UI and startup update checks; releases are installed manually.
- Migrates older saved match settings to the simplified rule format.
- All lobby members must use 0.1.4.

The intermittent native launch crash remains under investigation and is not claimed fixed by this release.

Validation: Gradle build passed, including 423 engine/network assertions and legacy settings migration checks.
