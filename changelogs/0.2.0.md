# 0.2.0

- Automatically returns every player to the lobby eight seconds after the game ends, saving worlds and preserving the lobby connection. Does not require the original leader to remain connected.
- Fixed lobby Enter/numpad Enter handling for Minecraft 26.3 and added a Send button; solo lobby chat is supported.
- Adapted OpenDraft's player colours: cyan for yourself, stable assigned colours for others, across chat and player displays.
- Added shared, coloured advancement announcements with duplicate and historical replay protection.
- Relay interruption and restoration notices are formal, grey and rate-limited; restoration messages no longer display the invite code.
- Includes the compact UI and fullbright extraction changes from 0.1.5–0.1.6. All lobby members must use 0.2.0.

The intermittent native launch crash remains separately deferred.

Validation: Gradle build and 446 assertions, including real TCP solo/multiplayer chat, advancement sender identity and deduplication, stable colour snapshots, and automatic-return timing without the original leader. In-game visual verification remains outstanding.
